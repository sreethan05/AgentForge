# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please report it privately:

1. Do **not** open a public issue.
2. Email the maintainer via the email listed on their GitHub profile, or use GitHub's private vulnerability reporting if enabled on this repository.
3. Include a description of the issue, steps to reproduce, and potential impact.

We will acknowledge reports promptly and keep you updated on the fix.

## Scope

Only vulnerabilities in this repository's code and configuration are in scope. Issues in third-party dependencies should be reported to their maintainers (or via Dependabot alerts).
