# Local Setup

## Prerequisites

- Node.js 18+
- npm

## Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/sreethan05/AgentForge.git
   cd AgentForge
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development build:
   ```bash
   npm run dev
   ```

If a script you need is missing, check `package.json` for the available scripts.
