# Contributing to AgentForge

Thanks for your interest in contributing!

## Getting started

1. Fork the repository and clone your fork.
2. Install dependencies with `npm install`.
3. Create a branch for your change: `git checkout -b my-feature`.

## Submitting changes

1. Make your changes and commit them with a clear message.
2. Push your branch and open a pull request against `main`.
3. Describe what changed and why in the PR body.

## Guidelines

- Keep PRs small and focused.
- Add or update tests where relevant.
- Follow the existing code style.
- Update documentation when your change affects usage.
